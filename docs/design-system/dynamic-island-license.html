Il segnale preannuncia un attraversamento pedonale.
该标志预告前方有人行横道。
💡 讲解
三角红边 = 危险警告标志(segnale di pericolo)。画行人 = 提前预告人行横道,所以陈述正确。
📚 词汇
attraversamento 横道(m.) pedonale 行人的 preannunciare 预告
✍️ 语法
动词 raffigurato 是过去分词作定语,性数和 segnale(阳性单数)一致。

设计说明(对齐 CLAUDE.md / cream 系统)

  • 描边/阴影:统一 2px ink900 实线 + 0 3px 0 ink900 落地阴影,小元素用 2px 版。
  • 圆角:卡片 24,小区块 18,药丸/徽章用 pill 或 14。
  • emoji=贴纸:全部套在彩色圆盘(disc)里,按语义配色 — 对=mint、错=rose、提醒=lemon、信息=sky、品牌=peach。
  • 答案徽章:V/F 或 A/B/C/D 用大徽章,正确绿(mint)、否定红(rose),一眼看到结论。
  • 结果字段:严格对应 ItalianLicenseResult(question_it/zh、answer、explanation_zh、vocabulary、grammar_notes)。
  • 文案 voice:用「看这题/再看一题」,不写「用户/点击拍照」;一段最多 1 个感叹号。
  • 截图不入镜:截屏瞬间先隐藏小岛与卡片,避免把岛拍进答案图。
  • 按钮 ≥ 56dp:小卡片内的快捷键 42dp(悬浮态可放宽),全屏 CTA 严格 56dp。
